One word for my Wi-Fi. The program writes it to `/output/entry.txt`:

> Situationship

Home Wi-Fi connects, drops, reconnects, never commits — exactly a situationship. It is funny on first read, true to how home Wi-Fi actually behaves, a fresh angle instead of the usual "buffering / slow / laggy", and it works as a Wi-Fi network name, which is what the winning word becomes.

`main.py` scores a shortlist of original candidate words against the judge's brief (on-subject fit, funny at once, true, fresh, works as one word) and writes the highest-scoring one. The run is deterministic and byte-identical every time.

## Run it

```sh
python3 main.py
```
